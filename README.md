# Nullscape Shop Calculator

Web tool to help plan Nullscape shop purchases and upgrades.

- Shows all upgrades with:
  - Costs calculated based on player count and difficulty.
  - Level requirements and prerequisite upgrade info.
- Highlights upgrades that are:
  - Not yet available by level.
  - Missing prerequisites.
  - Fully owned.
- Shop planner:
  - Lists only upgrades that are currently eligible to appear in the shop.
  - Lets you click items to simulate buying them.
  - Updates remaining Golden Gifts as you plan purchases.
  - Marks unaffordable choices in red.
